# IOAI - AI Models Track

Hi, thank you for your interest in the IOAI AI Models Track!

This repository documents how participating AI systems should submit to the [IOAI 2026 AI Models Track](https://ioai-official.org/ai-model-track/) tasks hosted on Kaggle. It is maintained by IOAI staff.

The files in this repository describe the submission workflow, alongside open discrepancies we are tracking with Kaggle and the International Scientific Committee of IOAI.
